# APS Logbook — time display update (19 October 2026)

- Settings → **Display & diary** → **Time format** offers 12-hour (AM/PM) and 24-hour (00–23).
- 12-hour is the default for new and existing installations. Examples: 12 PM, 1 PM, 2 PM after midday; 12 AM at midnight.
- The selected time format is saved with the existing local workspace data and persists across refreshes and backups.
- Changes only *presentation*: diary grid labels, six-hour period tabs, block accessibility labels/tooltips, work/rest change rows, live base clock, Driving screen clock.
- The original 24-hour time data used for computation, paper record PDF layout, storage and NHVR checks is **unchanged**.
- In 12-hour mode the end-of-day 12:00 AM is marked as next day on relevant diary row/tooltips.
- New tests: `tests/time-display.test.ts`.
